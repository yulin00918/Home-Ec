# 互動教室 V3.3.9｜三端白板初始化修正版

基於最後一個已驗收穩定的 V3.3.8。
本版完全不加入畫筆／圖形多人同步。

目的：
先修正教師端與桌機學生端「看起來像白板尚未開啟」的問題，
讓教師、手機、桌機學生端三端白板本體一致。

修正：
- app / main / canvas-wrap 改成明確 flex 高度鏈
- 白板工作區高度改由實際容器尺寸決定
- 初始化採 requestAnimationFrame + 120ms 二次量測
- 加入 ResizeObserver，容器尺寸變動時重新校正
- 不再用可能錯誤的初始 clientHeight 直接固定畫布
- 白板右上診斷列加入 surface 實際尺寸
- 新增「✅ 白板已就緒｜寬×高」狀態
- 教師端、手機端、桌機學生端都使用同一套初始化流程
- 便利貼／文字／圖片／八種活動板同步全部維持 V3.3.8 原狀

這一版先只驗收：
1. 教師開全班共編後，教師端看起來是正常白板
2. 手機端看起來是正常白板
3. 桌機學生端看起來是正常白板
4. 三端都顯示「✅ 白板已就緒」
5. 建立一個分類板，三端版面一致

全部通過後，再重新開始畫筆／圖形同步。
